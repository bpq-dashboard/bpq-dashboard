📁 YAPP File Transfer

💡 The terminal below stays active. You can type BBS commands while this panel is open.
⚠ FBB Mode Required for YAPP
Your current connection is on port ?. YAPP requires a separate FBB-mode connection (port 8011).

Select a file to send via YAPP to the connected station. Your terminal will switch to binary mode for the duration of the transfer. The receiving end must be expecting a YAPP transfer (typically you'd type a command like UPLOAD filename at the BBS prompt first).

Arm the receiver to watch for an incoming YAPP transfer. Before clicking Start, you should have already typed the appropriate command at the BBS prompt to initiate the send from the remote side (e.g. YAPP filename). Files are saved to /yapp-files/ on the server and a download link will appear when done.

Tip: If you're connected to a BBS (local or remote) and don't know what filenames are available, click Browse Files to list them and click one to start receiving.
